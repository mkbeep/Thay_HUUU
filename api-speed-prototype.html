Restaurant API Speed Prototype

Prototype nay dung de do thoi gian phan hoi cac API quan trong cua luong khach hang va admin. Chay backend truoc, sau do mo file HTML nay bang browser.

Cau hinh

API admin can token. Neu bi loi CORS, hay mo qua dev server tinh hoac cau hinh CORS backend cho origin cua browser.

API khach hang quan trong

Luong chinh: xem ban, tao session, xem menu, dong bo gio hang, tao order, xem order, yeu cau thanh toan, goi nhan vien.

API admin quan trong

Luong van hanh: dang nhap, xem order, doi trang thai mon, xem bill cho thanh toan, xac nhan thanh toan, xem yeu cau ho tro.
