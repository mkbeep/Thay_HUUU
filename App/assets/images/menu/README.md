## 📝 Yêu cầu ảnh:
- **Định dạng**: JPG hoặc PNG
- **Kích thước**: Tối thiểu 800x800px
- **Tỷ lệ**: Vuông (1:1) hoặc 4:3
- **Dung lượng**: Dưới 500KB mỗi ảnh
- **Chất lượng**: Rõ nét, ánh sáng tốt, màu sắc hấp dẫn

## 🔄 Sau khi thêm ảnh:
1. Chạy lệnh: `npm run update-images` (nếu có)
2. Hoặc restart Expo: `npm start -- --clear`
3. Kiểm tra ảnh hiển thị trong app
